# Project Context

Codex-style AI trading agent adapted for Hermes/local operation. Mission: beat SPX/SPY over the challenge window using Alpaca paper trading. Uses Yahoo Finance/yfinance top-100 volume as a liquidity filter, atilaahmettaner/tradingview-mcp via Hermes MCP tools as the primary screener/alpha layer, optional Perplexity for cited macro/news/catalyst context, Telegram notifications, and git-backed markdown memory. Pre-market writes final MCP-screened candidates to `memory/PREMARKET-CANDIDATES.json`; market-open orders only those candidates after rechecking the live top-volume liquidity filter and deterministic risk gates. Daily summary writes `memory/BENCHMARK-LEDGER.csv` and `memory/BENCHMARK-REPORT.md` so the bot judges itself against SPY/SPX. Live trading is out of scope unless explicitly approved later.
