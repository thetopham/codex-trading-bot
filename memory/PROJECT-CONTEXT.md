# Project Context

Codex-style AI trading agent adapted for Hermes/local operation. Mission: beat SPX/SPY over the challenge window using Alpaca paper trading. Uses Yahoo Finance/yfinance top-100 volume as a liquidity filter, atilaahmettaner/tradingview-mcp via Hermes MCP tools as the primary screener/alpha layer, Telegram notifications, and git-backed markdown memory. Pre-market writes final MCP-screened candidates to `memory/PREMARKET-CANDIDATES.json`; market-open orders only those candidates after rechecking the live top-volume liquidity filter and deterministic risk gates. Live trading is out of scope unless explicitly approved later.
