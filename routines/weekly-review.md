# Weekly Review — Hermes/Codex Routine

Safety: read-only review. Strategy changes must be explicit and documented.

1. Read the week's `memory/TRADE-LOG.md`, `memory/RESEARCH-LOG.md`, and current `memory/TRADING-STRATEGY.md`.
2. Pull Friday close account/positions with `scripts/alpaca.sh`.
3. Compute week return, trade counts, best/worst trade if data exists, and lessons.
4. Append a dated section to `memory/WEEKLY-REVIEW.md` with stats, what worked, what failed, and next-week adjustments.
5. Only edit `memory/TRADING-STRATEGY.md` if a rule clearly proved/fails and label the change.
6. Send one Telegram headline summary.
7. Commit memory changes; never force-push.
