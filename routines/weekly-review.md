# Weekly Review — Hermes/Codex Routine

Safety: read-only review. Strategy changes must be explicit and documented.

1. Read the week's `memory/TRADE-LOG.md`, `memory/RESEARCH-LOG.md`, `memory/BENCHMARK-LEDGER.csv`, `memory/BENCHMARK-REPORT.md`, and current `memory/TRADING-STRATEGY.md`.
2. Run `codex-trader weekly-review` to append the benchmark self-judgment to `memory/WEEKLY-REVIEW.md`.
3. Review the report for:
   - week bot return vs SPY return
   - cumulative alpha vs SPY
   - drawdown
   - exposure/cash deployment
   - whether any apparent alpha is just concentrated beta/risk-taking
4. If data exists, compare winners/losers by setup type: TradingView MCP technical screens vs Perplexity/news-catalyst context.
5. Only edit `memory/TRADING-STRATEGY.md` if a rule clearly proved/fails and label the change.
6. Send one Telegram headline summary.
7. Commit memory changes; never force-push.
